# Smart-Workout-Recommendation-System
I am excited to share a look into my latest Machine Learning project! The goal was to build a robust Smart Workout Recommendation System that generates personalized fitness plans based on user data.

Building a model is one thing, but building a maintainable, end-to-end pipeline is another. Here is a breakdown of the architecture I implemented:

The Pipeline Flow:
 Data Loading & EDA: Ingesting the dataset (11,000+ rows) and uncovering key trends.
 Preprocessing: Handling missing values and cleaning the data for accuracy.
 Encoding & Feature Engineering: Transforming raw data into meaningful features to improve model performance.
 Feature Selection: Identifying the most impactful variables to optimize training speed and accuracy.
 Model Training & Evaluation: Training multiple algorithms and comparing metrics to select the champion model.
 Prediction: Deploying the model to generate real-time workout recommendations.

Tech Stack: Python, Pandas, Scikit-Learn, Streamlit.
